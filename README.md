# MS Dhoni Career Statistics Analysis Dashboard

## 📊 Project Overview

This project presents an interactive **MS Dhoni Career Statistics Analysis Dashboard** created using **Microsoft Power BI**.

The dashboard analyzes MS Dhoni's cricket career performance across different years and provides insights into runs, innings, batting average, strike rate, boundaries, centuries and fifties.

## 🎯 Objectives

* Analyze MS Dhoni's career batting performance
* Track runs scored across different years
* Analyze yearly performance trends
* Compare 4s and 6s
* Analyze centuries and fifties by year
* Identify the best-performing year
* Present cricket statistics through an interactive dashboard

## 🛠️ Tools & Technologies

* Power Query

* Data Visualization

The dashboard includes:

* Runs by Year
* 100s and 50s by Year
* Best Performing Year
* Year Range Filter
* Format Filter

## 📊 Dashboard Features

### 1. Year Range Analysis

Users can analyze MS Dhoni's performance across a selected range of years.

### 2. Runs by Year

A yearly bar chart shows the variation in runs scored during his career.

### 3. Boundaries Analysis

The dashboard provides a visual comparison of fours and sixes.

### 4. Centuries & Fifties

The dashboard displays the number of centuries and fifties scored in each year.

### 5. Best Performing Year

The dashboard highlights the year with the strongest performance based on the selected analysis.
